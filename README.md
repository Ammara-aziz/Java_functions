# Compile the Program:
Use the javac command followed by the full filename. This creates a .class file containing bytecode.
#Terminal
# javac MyFileName.java

# Run the Program: 
Use the java command followed only by the class name (do not include the .java or .class extension).
=> Terminal 
# "java MyFileName"

# using Git in Terminal 
To Stage all changes (every updated file in the current directory and its subdirectories): Use 
# git add . 


Alternatively, 
# git add -A or git add --all 
stages all changes , including deletions, across the entire repository.
